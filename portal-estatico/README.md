# Portal estudiantil estático

Maquetación inspirada en las cinco capturas compartidas. Proyecto sin backend, sin formularios funcionales, sin consumo de APIs y sin registro real de eventos.

## Archivos
- `index.html`: pantalla principal con perfil, accesos y calendario.
- `mis-eventos.html`: vista Mis Eventos vacía.
- `eventos-disponibles.html`: vista Eventos Disponibles con tarjeta de conferencia.
- `styles.css`: todos los estilos y animaciones.
- `script.js`: exclusivamente apertura y cierre del menú lateral.
- `assets/`: recortes gráficos de cabecera extraídos de las capturas proporcionadas.

## Cómo verlo
Abre `index.html` directamente en un navegador. Las pestañas de eventos y los enlaces Inicio / Eventos y diplomas conducen a otras páginas HTML **estáticas**. Los restantes accesos son solo elementos visuales.

Los iconos Bootstrap Icons cargan desde un CDN; para verlos se requiere internet. No se necesita instalar nada ni ejecutar un servidor.
